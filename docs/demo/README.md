# デモ資材

本アプリの成果は Admin 画面・チェックアウト・注文ステータスページの中にしか現れず、
ストアURLを渡すだけでは発注者に見せられない。この制約への対策として、動作の要所を
画面録画（GIF）・スクリーンショットで記録したもの。すべて `chanoka-demo`
（開発ストア。実在の店舗ではない）で撮影した。名入れの「山田」「佐藤」は架空の氏名。

| ファイル | 内容 |
|---|---|
| `01-cart-noshi-fee.gif` | カートで熨斗（表書き・名入れ・のし種別）を指定すると、のし代・包装料が独立したカート行として加算される |
| `02-wrap-fee-free.gif` | 数量を増やして合計金額がしきい値（¥3,000）に到達すると、チェックアウトで包装料が無料になる |
| `03-admin-noshi-card.png` | 受注画面（Admin UI Extension）の熨斗情報カードと、印字用データの出力 |
| `04-admin-correction.gif` | 受注後に出荷担当が表書きを訂正し、印字用データへ即座に反映される（FR-18） |
| `05-customer-order-status.png` | 購入者側の注文ステータスページ（Customer Account UI Extension）に熨斗情報カードが表示される。料金行（のし代・包装料）にはカードが出ないこと、包装料無料の割引も同時に確認できる |

対応する実装・実機確認の詳細は `../spec.md` の各構成要素の節を参照。
